# Frontend-Wireframes

Grobe UI-Skizzen aller Views als **Obsidian Canvas** (`.canvas` = JSON).

**Ansehen:** Ordner in [Obsidian](https://obsidian.md) als Vault öffnen → `00-Overview.canvas` zeigt die Sitemap mit allen Klick-Pfaden.

## Views
- **00-Overview** — Sitemap / Navigation
- **Landing** — öffentliche Startseite
- **Auth** — Login / Registrieren / Passwort-Reset
- **Home** — Dashboard nach Login
- **Projects** — Projekt-Liste
- **Project-Detail** — ein Projekt + letzte Scans
- **Scan-History** — alle Scans eines Projekts
- **Scan-Detail** — Befunde, Fix-Vorschläge, Review, Export
- **Account** — Kontoeinstellungen
- **Legal** — Impressum / Datenschutz
- **404** — Fehlerseite
