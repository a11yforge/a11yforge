How to determine the label text:
1. If the element has a "placeholder" attribute, use its value as the basis for the label. A field with placeholder="Telefon" is a telephone field and must be labelled accordingly (e.g. "Telefon"), NOT with a generic word.
2. If there is no placeholder, use any other clue in the snippet: the "name" attribute, the "type" attribute (an input[type="email"] is an email field, input[type="number"] a numeric field), or an existing "value".
3. Only if the snippet contains no usable clue at all, choose a short, sensible label based on the input type. Never fall back to meaningless words like "Eingabe", "Feld", "Input" or "Text" when a better clue is available.

How to apply the label (pick the most appropriate method):
- Preferred: add an explicit <label> connected via matching for/id. If the element already has an id, reuse it; if it has none, add a descriptive id and reference it from the label's "for".
- Alternative: if adding a <label> element does not fit the snippet, add an "aria-label" attribute with the label text.
- Preserve all other attributes, classes, and structure. Do NOT change the input's "type", its "placeholder", or any unrelated attribute. Add the label, nothing else.

Write the label text in {{language}}.

Never produce any of these — they defeat the purpose of a label:
- generic placeholders as the label: aria-label="Eingabe", <label>Feld</label>, aria-label="Input"
- a label that ignores an available placeholder or type (e.g. labelling a placeholder="Telefon" field as "Textfeld")
- changing the input type or adding unrelated attributes

Respond with ONLY the corrected HTML snippet, wrapped in <fix>...</fix> tags.
