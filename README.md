# A11yForge

Hybrid Accessibility Remediation Tool. Regelbasierte und LLM-gestützte
WCAG-Konformitätsprüfung mit halbautomatischer Behebung.

## Module

- `backend/` Spring Boot, REST-API, Auth, Persistenz
- `scanner/` WCAG-Scanner als eigener Service (axe-core, Headless Browser)
- `frontend/` Vue 3 mit TypeScript
- `docs/` Architektur und ADRs
